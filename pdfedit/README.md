# PDFページ整理エディタ - Android PWA化 セットアップ

このフォルダには、既存の `index.html`（PDFページ整理エディタ）をAndroidにインストール可能な
PWA（Progressive Web App）にするためのファイル一式が入っています。

```
index.html            … 元のエディタ + PWA用タグ/SW登録を追加したもの
manifest.json         … アプリ名・アイコン・起動時の見た目を定義
sw.js                 … オフラインキャッシュ用のService Worker
icon-192.png          … ホーム画面アイコン(192x192)
icon-512.png          … スプラッシュ画面等に使うアイコン(512x512)
icon-512-maskable.png … Android用マスカブルアイコン(512x512)
```

## 1. ホスティングする

PWAとして動作させるには **HTTPS**（またはlocalhost）でこの5ファイルを
すべて同じフォルダに置いて配信する必要があります。ビルド不要・このまま配置するだけでOKです。

おすすめの方法（無料・職場PCでビルド不要）:

- **GitHub Pages**
  1. GitHubに新しいリポジトリを作成
  2. このフォルダの5ファイルをそのままアップロード（ドラッグ＆ドロップ可）
  3. リポジトリの Settings → Pages で公開を有効化
  4. 発行されたURL（例: `https://ユーザー名.github.io/リポジトリ名/`）にアクセス

- その他: Cloudflare Pages、Netlify Drop なども同様にドラッグ＆ドロップだけで公開できます。

## 2. Androidスマホでインストールする

1. スマホのChromeで上記URLを開く
2. 右上の「⋮」メニュー → 「アプリをインストール」（または自動で表示されるバナーの「インストール」）をタップ
3. ホーム画面にアイコンが追加され、以降はアイコンをタップするとアプリのように全画面で起動します

## 3. オフラインで使う

初回にオンラインで一度開いてキャッシュが作られれば、以降は機内モードでも起動・利用できます
（PDFの読み込み・編集・保存はすべて端末内で完結しており、外部通信は行いません）。

## 4. アプリを更新したいとき

`index.html` の中身を更新した場合は、`sw.js` の `CACHE_VERSION` の値
（例: `pdf-editor-v1` → `pdf-editor-v2`）を変更してから再アップロードしてください。
バージョンを変えないと、古いキャッシュが使われ続けて更新が反映されません。
